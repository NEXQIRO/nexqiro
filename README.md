# NEXQIRO — Master Super Admin Control Center

Master Super Admin Control Panel for NEXQIRO.
GitHub Repository: https://github.com/NEXQIRO/nexqiro

## Features
- Complete Firebase Authentication & Master Super Admin Authorization
- Connected to Render Backend: `https://nexqiro-backend.onrender.com`
- Real-time token verification against Backend `/api/me`
- User Admin Management (Add, Edit, Suspend, Permissions)
- Independent Tenant & Site Isolation
- Special Internal Balance Transfer (User Balance -> User Admin Wallet)
- Games Management & Assignment Matrix with Maintenance Toggle
- Central Tournaments Master Hub
- Turnover Management & Progress Tracking
- Double-Entry Master Wallet Ledger & Fund Request Approval Engine

## Deployment on GitHub Pages
1. Push all files (`index.html`, `firebase-config.js`) to the `main` branch of repository `NEXQIRO/nexqiro`.
2. Go to Repository **Settings** -> **Pages**.
3. Under **Branch**, select `main` and root `/`, then click **Save**.
4. The site will be published at `https://YOUR-GITHUB-USERNAME.github.io/nexqiro/`.

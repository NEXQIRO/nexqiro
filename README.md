# NEXQIRO — Master Super Admin Control Center

Master Super Admin Control Panel for NEXQIRO.
GitHub Repository: https://github.com/NEXQIRO/nexqiro

## Features
- Complete Firebase Authentication & Master Super Admin Authorization
- Connected to Render Backend: `https://nexqiro-backend.onrender.com`
- Real-time token verification against Backend `/api/me`
- Full Dashboard, Master Wallet, Fund Requests Hub, User Admin Balances, Games Control Center (with maintenance mode toggles), 22-Granular Permission Matrix, Site Registry, and Central Audit Trail preserved 100%.

## Deployment on GitHub Pages
1. Push all files from `nexqiro/` to the `main` branch of repository `NEXQIRO/nexqiro`.
2. Go to Repository **Settings** -> **Pages**.
3. Under **Branch**, select `main` and root `/`, then click **Save**.
4. The site will be published at `https://YOUR-GITHUB-USERNAME.github.io/nexqiro/` (or your custom domain).
